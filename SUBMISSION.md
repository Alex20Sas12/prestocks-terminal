## Pitch

PreStocks Terminal is the analytics layer the pre-IPO token market is missing: a live terminal that shows, for all 8 PreStocks tokenized private companies, where the on-chain token actually trades versus the company's mark price — premium, discount, valuation gaps, volume and holder growth — plus a daily auto-generated "Pre-IPO Brief" digest that can be published to X/Telegram by cron. It answers the one question every PreStocks trader has ("am I paying up for OpenAI liquidity, and by how much?") in one page, with zero friction, and it funnels users straight into PreStocks tokens via Jupiter swap deep-links.

## What it does

1. **Premium/discount watch** — merges PreStocks mark prices with live Jupiter DEX prices in one server-side call; every token card shows token price, mark price, premium %, 24h change, liquidity, mark vs implied valuation. Market-wide summary: combined valuation ($5T+), total liquidity, average premium.
2. **Per-token deep dives** — 90-day daily volume and 60-week holder charts (inline SVG, zero dependencies), launch dates, supply, plain-English premium explainer, and a "Trade on Jupiter" deep-link that turns research into on-chain action.
3. **Pre-IPO Brief** (`/brief` + `/api/brief`) — a daily markdown digest generated live from upstream data: widest premium/discount, volume movers day-over-day, fastest-growing holder bases, full board. The exact same markdown an automated cron posts to X/Telegram every morning.

## Tech stack

- Static HTML/CSS/JS (light fintech design, mobile-friendly, SEO meta per page, no framework, no npm deps)
- 3 Vercel serverless functions (Node) proxying prestocks.com + Jupiter APIs, edge-cached (`s-maxage` 300–3600s) — solves CORS, keeps upstream load minimal, runs entirely on the free tier
- Live verification suite (`node test.js <url>`) asserting API shapes and premium math on every deploy
- No database, no keys, no on-chain transactions — 100% read-only public data, $0 operating cost

## PreStocks-only

All data shown is PreStocks tokens and Jupiter markets for PreStocks mints. No non-PreStocks pre-IPO tokens are integrated.

## Life after hackathon

- The Brief pipeline is production-ready on day one: a Hermes cron job fetches `/api/brief` and publishes to X/Telegram daily — a standing distribution channel driving attention back to PreStocks tokens (the "share / grow / automations / AI agents" corner of the bounty).
- Roadmap: premium alert thresholds (notify when |premium| crosses X%), funding-round event annotations, comparison with xStocks/Tessera marks behind an explicit opt-in (separate from bounty scope), embeddable premium widgets for PreStocks ecosystem pages.
- Operating cost is $0 (Vercel free tier + public APIs), so it stays alive indefinitely; we already run a fleet of similar Vercel products.

## Judging notes

- **Originality:** nobody publishes premium-to-mark as a first-class metric for pre-IPO tokens; the Brief-as-API pattern (digest generated by endpoint, consumed by both humans and cron bots) is novel for this niche.
- **Technical soundness:** server-side merge of two independent price sources, cached functions, assert-based live test suite, zero-dependency charts — verified working end-to-end on mainnet data.
- **Real usage:** the premium/discount question is asked daily in PreStocks/DeFi communities; the terminal answers it in one URL, and the Brief creates a recurring daily touchpoint.
